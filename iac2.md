# Script de Provisionamento Web - Apache

![Infraestrutura como Código](https://img.shields.io/badge/IaC-Apache_Provisioning-blue)
![Shell Script](https://img.shields.io/badge/Shell_Script-Bash-green)

Script de automação para provisionamento de servidor web Apache seguindo princípios de Infraestrutura como Código (IaC).

## Funcionalidades Principais

- Atualização do sistema
- Instalação de pacotes:
- Apache2 (servidor web)
- Unzip (manipulação de arquivos)
- Deploy automático:
- Download da aplicação do GitHub
- Extração e cópia para diretório do Apache
